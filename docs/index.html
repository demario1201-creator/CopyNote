单击即复制

点击任意便签或色卡圆点，内容直入剪贴板，绿色闪光反馈。无需选中、无需 Ctrl+C。

迷你悬浮条

窗口收成屏幕边缘一条彩标。悬停预览、滚动翻页、点击即取，全程不展开窗口。

自由拖动

按住迷你条顶部拖拽点，移到屏幕任意位置；松开自动吸附到最近边缘，高度随你选。

🎨

色卡直达

圆点即「最近颜色」，点击复制最近内容；右键菜单，同色便签任你挑。同色合并不重复。

快速开始

两种方式，任选其一

① 下载 Release（推荐）

下载后解压拖入「应用程序」
# 首次打开被拦截？右键 → 打开 即可
# 或命令行去除隔离标记
$ xattr -dr com.apple.quarantine /Applications/CopyNote.app

② 源码编译

Terminal
$ git clone https://github.com/demario1201-creator/CopyNote.git
$ cd CopyNote
$ swift build --disable-sandbox
$ bash script/build_and_run.sh run
Build complete! ✓

系统要求：macOS 14.0+ (Sonoma) · Apple Silicon

快捷键

全部可在设置中自定义，冲突自动提示

快捷键功能作用域
⌥ ⌘ N切换主窗口 / 悬浮条全局
⌘ N新建便签应用内
⌘ E编辑选中便签应用内
⌘ D复制一份副本应用内
⌘ ↵复制选中便签内容应用内
⌘ ⇧ V打开复制历史应用内
⌫删除选中便签应用内
